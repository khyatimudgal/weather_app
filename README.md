# 🌤️ Weather App

A fully responsive weather app built with React and Vite. Search any city worldwide for real-time weather data with dynamic backgrounds.

## ✦ Features

- 🌡️ Current temperature with °C/°F toggle
- 🌬️ Wind speed, humidity, UV index
- 🌧️ Chance of rain today
- 😷 Air quality index (AQI)
- 🎨 Dynamic backgrounds based on weather conditions
- ⌨️ Enter key search support
- 📱 Fully responsive design

---

- React + Vite
- JavaScript
- CSS
