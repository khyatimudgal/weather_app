# 🌤️ Weather App

A fully responsive weather app built with React and Vite. Search any city worldwide for real-time weather data with dynamic backgrounds.

## ✦ Features

- 🌡️ Current temperature with °C/°F toggle
- 🌬️ Wind speed, humidity, UV index
- 🌧️ Chance of rain today
- 😷 Air quality index (AQI)
- 🎨 Dynamic backgrounds based on weather conditions
- ⌨️ Enter key search support
- 📱 Fully responsive design

## ✦ Getting Started

1. Clone the repo
   ```bash
   git clone https://github.com/khyatimudgal/weather_app.git
   cd weather_app
   ```

2. Install dependencies
   ```bash
   npm install
   ```

3. Create a `.env` file and add your WeatherAPI key
   ```
   VITE_API_KEY=your_api_key_here
   ```

4. Run the dev server
   ```bash
   npm run dev
   ```

Get a free API key at [weatherapi.com](https://www.weatherapi.com)
